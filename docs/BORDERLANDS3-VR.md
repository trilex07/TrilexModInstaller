# Borderlands 3 VR for Steam and Epic Games Store

1. In Borderlands 3, select DirectX 11 under graphics settings. Restart once
   to save it, then close the game. Remove any DX12 launch options.
2. In Trilex Mod Installer, select **Borderlands 3 VR**. Use the detected
   Steam or Epic folder, or browse to the folder for the store you own.
   The installer checks the executable and selects its matching module.
3. Start SteamVR and launch Borderlands 3 from your store's launcher.
   If the game opens in SteamVR cinema, try the launch options
   `-dx11 -emulatestereo` in that launcher.

Hold L3+R3 to recenter. The installer's PSVR2 Toolkit setup enables optional
gaze and Sense trigger features on supported hardware. Frame Generation can be
enabled in VR Settings. Restore or uninstall from Trilex Mod Installer.

Two-player LAN tests on Steam covered joining, combat, revives, reconnecting
and Iron Bear's rear turret. The Epic module is a preview. Its native build
and installer checks do not establish gameplay, headset or co-op acceptance.
