# Borderlands 3 VR on Steam

1. In Borderlands 3, select DirectX 11 under graphics settings. Restart once
   to save it, then close the game. Remove any DX12 launch options.
2. In Trilex Mod Installer, select **Borderlands 3 VR** and install to the
   detected Steam folder.
3. Start SteamVR and launch Borderlands 3 from Steam. If it opens in SteamVR
   cinema, try the Steam launch options `-dx11 -emulatestereo`.

Hold L3+R3 to recenter. The installer's PSVR2 Toolkit setup enables optional
gaze and Sense trigger features on supported hardware. Frame Generation can be
enabled in VR Settings. Restore or uninstall from Trilex Mod Installer.

Two-player LAN tests covered joining, combat, revives, reconnecting and
Iron Bear's rear turret. This package targets the tested Steam build.
