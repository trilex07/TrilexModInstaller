## English

Trilex Mod Installer and SingularityVR are unofficial, free fan projects. We are
not affiliated with the game's developer or publisher and do not claim their
endorsement. A compatible, legitimately owned copy of the game is required.

Our code is available under MIT. This license does not claim rights to the game,
recordings, voices, models or other third-party materials. Dependencies retain
their own licenses and attribution notices.

Preview 0.1.0 provides source code and local-processing parameters for seven
sound/music banks. It contains no recordings, voice model weights or game files.
Audio is generated locally from the user's own files. Exact input and output
identities are checked; these recipes are not a universal patch for every edition.

The provenance and permissions for some final dubbing takes remain unverified.
Those recordings are not included, are not labeled MIT, and their automatic voice
cloning is not enabled. Public source availability does not imply that all optional
packages are installable. The installer's package availability reflects actual
review/publication status.

This is an experimental preview, provided without warranty as described in LICENSE.
Installation is voluntary. Do not disable operating-system security protections.
Please submit provenance concerns or rights-holder requests through the repository;
we will review them and correct or remove affected material where appropriate.
This statement is not offered as a substitute for permission or a license.
